# views/livewire/examenes — Vistas de gestión de exámenes

## Para qué sirve
Renderiza el CRUD de exámenes: listado, creación, edición y detalle.

## Qué contiene
- `index.blade.php` (listado con filtros/paginación).
- `create.blade.php`, `edit.blade.php`, `show.blade.php`.

## Rol en la arquitectura
- **Capa:** Presentación (render del feature `Examenes`).
- **Conoce:** solo los props de su componente.

Fuente: `arquitectura.md` (sección 4).
